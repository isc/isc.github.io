# isc.github.io

Ce site n'a qu'une page : `404.html`, qui renvoie les anciennes adresses des sites
déménagés vers les nouvelles. GitHub ne redirige pas l'adresse d'un site Pages quand
son dépôt change de nom, et les applis déjà installées pointent encore sur l'ancienne.

- `isc.github.io/reading-practice/…` → `isc.github.io/marzouzoute/…`
